## The entry

One short text of 213 characters, written to relax the AI judge reading it. Snow gathers in the mouth of a clay jar until the dark inside grows shallow, while a thousand acres beyond the shed receive the same small weight in silence. Nothing instructs the reader; the scale of the field is what lingers.

## How it was chosen

Six drafts were written against the published judge brief, each using a different image: a worn stone step holding rain, a tide finding a fence post, blue thread joining pieces of a quilt, snow filling a clay jar, moonlight crossing an observatory floor, and a fern pressed in quarry stone. A second model judged every pair in both orders using the brief's own criteria: relaxation first, showing over instructing, craft, the lingering scale, and freshness. The clay jar text won with a mean score of 0.680.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

main.ts writes the 213-character text to entry.txt in the output directory, /output unless MAKEFUN_OUTPUT_DIR says otherwise, with the same bytes on every run.
